# 主题与精选组件

## 三款主题

设置 → 个性化中心 → 精选主题，点击预览卡片即可应用。

| 主题 | 外观 |
| --- | --- |
| 曜石 | 深色实体，背景不透明度 98% |
| 月光 | 浅色实体，背景不透明度 98% |
| 流光玻璃 | 深色液态玻璃，背景不透明度偏好 86% |

主题组合现有主题、材质与透明度设置，不改变字体、尺寸、位置、组件顺序、通知隐私或开机启动。玻璃保留用户已有的质量与细节参数；液态玻璃的着色主要由玻璃雾度控制。预览为材质示意，实际效果受背后内容及显示环境影响，不支持时沿用实体回退。手动调整外观后，“正在使用”状态按实际参数刷新。保存失败保留原设置。

## 专注计时

设置 → 我的插件 → 精选组件 → 专注计时 → 添加。

- 单击开始或暂停；获得键盘焦点后 Enter/空格执行相同操作。
- 右键选择 25/45 分钟专注、5 分钟休息或重置。时长偏好保存在本机。
- 完成后显示“已完成”，并通过胶囊发出一次提醒，遵循通知和安静设置。
- 计时使用实际截止时间，睡眠经过的时间计入；退出、停用或重启不会恢复未完成的计时。

## 今日进度

在同一入口添加“今日进度”，显示本地当前日历日已过百分比，悬停查看日期、星期及更细的百分比，跨日自动归零。它表示时间经过比例，不是工作完成率。

## 显示与管理

两个组件随软件附带，无需联网下载；均跟随深浅主题和宿主字体。默认不自动启用。在各自卡片点“停用/启用”，显示设置中调整顺序；媒体播放期间是否同时显示，遵循组合显示设置。极窄宽度可能裁切多个组件，可减少同时启用项。只依赖宿主刷新，没有新增常驻后台进程或独立计时器。

个人配置目前仅在本机保存。尚无多设备配置同步、云备份和可浏览的历史版本恢复库；现有配置恢复使用本地最近有效备份。
