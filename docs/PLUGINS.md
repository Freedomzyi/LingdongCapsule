# 灵动胶囊插件（开发中）

当前支持用户主动安装 ZIP 插件包或加载本地 DLL、调整启用顺序、停用、卸载及替换同 ID 包。插件实现本仓库独立定义的 `Capsule.PluginApi`，不宣称兼容 NotchPeninsula DLL。已安装但停用的包可直接重新启用、删除或重试清理；市场浏览、校验下载与单项/批量更新已接入；时钟预览示例真实上架/下载已验收；逐组件混合排序已通过回归，两个定制组件统一管理及完整实机验收仍待完成。

## ZIP 插件包

包根目录必须包含 `plugin.json`，例如 `{"id":"example.clock","name":"示例时钟","version":"0.1.0","entry":"Clock.dll"}`。入口和依赖均使用包内相对路径；安装至自己的 Plugins 子目录，再校验实际插件 ID。已启用列表保存解压后的入口，重启不会重复解压。安装不会覆盖开发目录或原 NotchPeninsula 文件。

当前限制为 256 个条目、单文件 16 MiB、合计 64 MiB。拒绝相对路径越界、绝对路径、符号链接、Windows 保留文件名、大小写重复路径、伪造安装凭据以及无效入口。恶意包矩阵已覆盖上述边界，拒绝发生在创建安装目标之前。

安装后核对实际 ID 和版本。同 ID 替换或配置写入失败时恢复旧组件、位置、启用路径及宿主偏好；初始化期间宿主设置保存延后到提交，通知请求返回未接受。旧组件自身恢复失败时隔离故障项并记录，不能承诺回滚插件自己对外部文件或进程做出的修改。停止插件保留文件。卸载仅删除本程序安装目录内且凭据匹配的包，不删除外部 DLL；文件被占用时保留凭据并排队到下次启动重试。个人插件偏好保留。旧升级目录与失败安装目录按同一凭据边界清理，锁定或清理失败进入重试队列；配置目录不可写时不能保证新清理队列已经落盘，目录列表可从有效安装凭据发现这些未启用包，供用户清理或重新启用。

## 开发接口

- 使用 .NET 10，目标 `net10.0-windows10.0.19041.0`，启用 WPF，并引用 `src/Capsule.PluginApi/Capsule.PluginApi.csproj`。
- 程序集只导出一个非抽象 `ICapsulePlugin` 实现，并提供无参数构造函数。
- `Identity` 提供唯一 ID、显示名和版本。ID 为小写字母开头的 3～80 位字母、数字、点或连字符；版本使用 `System.Version` 支持的格式。
- `CreateWidget` 返回没有父级的 WPF 组件；`Update` 接收时间、主题和媒体快照，在 UI 线程更新，不应执行阻塞网络或重计算。
- `Dispose` 释放自己的计时器、事件订阅和其他资源。回调失败时宿主移除该插件组件并记录故障，不中断其他插件更新。
- `ICapsulePluginHost` 提供当前媒体、按插件 ID 隔离的字符串设置及通知请求。通知仍遵守软件总开关、来源过滤、隐私和安静时段。

## 使用与限制

在“我的插件”选择可信 DLL，确认后加载。DLL 及依赖保留在原目录，重启会重新加载已启用项；停用会移除组件并从启用列表移除路径，不删除源文件。插件与宿主同进程运行，不是安全沙箱。

基础示例及故障用例位于 `tests/Capsule.WindowsTests/PluginTests.cs`。该测试程序集只用于验证，不作为用户插件发布。复验命令：`dotnet run --project tests/Capsule.WindowsTests -c Release -- --plugin-test`。

已验证独立程序集加载、共享 API 类型、组件更新、停用释放、回调异常隔离、包安装与身份核对、升级失败恢复、锁定文件卸载重试，以及实际岛体中的插件时钟显示。已验证首次安装/升级保存失败、停用/卸载保存失败及排序保存失败的恢复。停用和卸载在配置提交前保留当前组件及文件；排序失败恢复界面顺序和重启顺序。启动加载及运行更新故障会移出重启启用列表并记录原因，避免下次启动重复加载失败项。插件市场、混合 DPI、跨版本兼容与复杂插件资源释放仍需专项验收。

## 已安装目录

“我的插件”列出有效安装凭据对应的未启用包；扫描只读取限定大小的清单，不反射加载 DLL。重新启用会再次检查包内入口路径、链接、清单与实际插件 ID/版本。包目录中的 DLL 不能绕过凭据验证作为普通外部 DLL 加载。

清单损坏但凭据有效的包显示错误，可按安装目录范围删除；凭据无效或目录为链接时不提供删除入口。待清理项不能直接启用，可重试清理。删除前保存队列，保存失败不删除文件。每次最多检查 512 个目录，超限显示提示，不扫描整个磁盘。

目录列表、停用后重启用、安装入口版本不符拒绝、删除保存失败、损坏清单清理及实际设置页面已经 Windows 测试验证。`artifacts/verification/plugins/installed-page.png` 是私有 WPF 渲染证据，不代替物理点击或 Owner 验收。

## 官方市场（开发中）

“我的插件”可打开独立市场窗口，支持搜索、类别筛选、名称/版本排序、只看更新、单项安装或更新，以及已安装组件的启用状态。目录从本仓库 `plugins/catalog.json` 读取；当前已上架 1 个明确标记为 API 预览的时钟示例，ZIP 来自本仓库插件预览附件。单项和批量更新保留启用/停用状态，实际客户端已完成 GitHub 下载、SHA/身份核验及岛体显示。完整构建也提供本地示例包。

目录格式为 `{"schema":1,"packages":[]}`。每项字段为 id、name、version、description、downloadUrl、sha256、minimumHostVersion、author、license、category；全部文本与条目数量有限制。只允许本仓库的 HTTPS 原始文件或发布附件，附件重定向限 GitHub 资产域名。不关闭证书检查，不读取 GitHub 登录令牌。

下载先限制响应体积，再核对 SHA256、ZIP 清单 ID/版本和宿主最低版本，最后进入已有包验证与配置事务。下载临时包在安装结束后删除。打开窗口才读取目录，关闭窗口取消网络请求；安装需用户确认同进程信任边界，不在后台自动执行更新。

`--market-test` 使用注入 HTTP 响应和真实构建的 ZIP：覆盖目录重复项/超限、下载校验失败、身份不符、宿主版本不符、私有/外部 URL、重定向、取消和文件清理；还验证实际市场搜索/更新/已启用状态，并把校验后的包安装到实际岛体。注入响应用例与线上验证分别记录；官方时钟预览包的真实链路已额外通过 --market-live --download 验证。

## 统一组件排列

“我的插件”统一管理内置的 *居中时钟、*空闲信息面板及外部组件。内置开关沿用 ClockEnabled/OverviewEnabled，时钟布局和明日天气也只保留此处一份入口；显示页提供管理导航，不复制开关。内置模块随主程序提供，可停用/恢复，不单独删除程序文件；外部组件继续使用独立包的安装/卸载事务，不宣称兼容原版 DLL。

停用保留布局、排列位置、城市和天气选择；停用信息面板立即关闭详情，并取消进行中的天气请求，迟到结果不能写入缓存。重新启用后可继续更新。时钟在排列列表与管理页统一标为 *居中时钟；信息面板属于点击详情，不占用横向排列位置。

“显示设置”的组件排列是唯一排序入口，可在时间/日期、硬件、媒体和每个运行插件之间交错排列。移除了旧的媒体前后选择、空闲顺序选择及插件页重复箭头。旧配置的 HardwareFirst/MediaFirst 在没有 ComponentOrder 时迁移；新 ComponentOrder 为唯一顺序依据。停用组件的历史位置保留，新组件默认追加。

布局承载实际插件元素，保留交互，不使用截图或静态复制。普通每秒刷新不会拆卸重建组件父级；只有顺序或集合变化时重新排列。插件排序与重启启用路径同步提交，保存失败恢复原顺序。空闲自动测量支持时钟文本变化；组合态为媒体留空间，窄宽裁切而不压缩字号。

插件可以自行设置控件颜色，宿主切换主题或透明度时不递归覆盖插件内部控件。未设置前景色的控件从承载槽继承 IslandInk；需要更多主题适配的插件使用 PluginFrame.DarkTheme。实际岛体已验证插件自选颜色保持，以及清除自选颜色后深浅主题继承。

已验证 80/195/280/300 宽度、媒体/硬件/时间/两个插件的交错和不重叠，独立开关、展开播放器和待机退出恢复，以及实际显示页箭头和配置保存失败恢复。物理输入、混合屏幕与完整资源占用仍需按交付计划验收。

## 可选外部媒体时间轴

插件可在 ICapsulePlugin 之外实现 ICapsuleTimelineSource.ReadTimeline(PluginMediaSession)。宿主在 UI 线程读取缓存快照；不要在该方法中进行网络、CDP、文件读取或等待。只有网易云/酷狗来源、音乐会话且系统没有有效时长时才会调用。插件须核对请求的 SourceId 与自己的数据来源，不匹配或数据失效时返回 null。

返回 PluginTimeline(TrackKey, Position, Duration, Playing, Priority)：TrackKey 是当前曲目的稳定键，切歌必须改变；位置非负、时长大于零。宿主在相同快照之间用单调计时补进度，暂停冻结，拖动和切歌重置锚点，位置限制在时长内。多个有效提供者按 Priority 最大值选择，同优先级按当前插件顺序；无效数据跳过，读取异常按插件故障处理并停用。

时间轴可用于进度显示与歌词同步，不替换系统会话的标题、艺人、专辑、封面身份或原始元数据时长。启停、数据失效及系统恢复有效时长时回到系统数据；不提供不存在的定位能力。该扩展不执行原版 DLL，也没有内置或自动开启第三方软件的 CDP 调试端口。实际数据采集由可信插件在后台完成。

`--timeline-test` 验证独立加载的可选接口、优先级/坏数据/故障/停用、单调插值边界；再用自有静音 SMTC 的缺失/有效时间轴验证原生优先及身份不变，并在实际展开岛体核对时长显示、禁止虚假 seek 和停用恢复。此证据不是实际网易云或酷狗的 CDP 兼容验收。
