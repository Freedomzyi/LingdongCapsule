# 0.1 开发与发布方案

> **范围已被 Owner 更新：必须完整对齐本机 NotchPeninsula 定制版，以下为早期核心原型方案的历史技术依据，不再作为缩减交付范围的理由。当前唯一功能范围与进度见 [完整对齐清单](PARITY.md)。**

目标：一个 Windows 11 x64 上可独立构建和运行的桌面胶囊；先保证状态和恢复正确，再扩展功能。

技术：C# / .NET 10 / WPF；Windows 媒体及通知通过 WinRT 接入。界面与状态核心分离，不引入服务端、数据库、插件框架或网页运行时。

范围：24 小时时钟、系统媒体信息/封面和上一首/播放暂停/下一首、通知隐私预览与展开收回、按来源静音、宽度/折叠高度/动画设置、主窗口截图排除、托盘退出、可选开机启动与首次引导、当前用户安装与卸载。

Owner 后续确认：所有界面、按钮和调整器均采用 iOS 风格；折叠高度默认 35 逻辑像素，并可调节；日常启动只驻留托盘，使用原创图标；安装后展示引导。独立产品本身的功能不沿用上游定制项星号，说明统一使用名称旁的 i 悬停入口。

不在 0.1 范围：歌词服务、天气、硬件面板、进程清理、自动更新、插件市场、账号、遥测。系统媒体和通知不提供的信息不推测补齐。

状态优先级：通知 > 正在播放媒体 > 时钟。暂停但媒体会话存在时，点击时钟可访问控制。通知到达只覆盖展示，媒体状态继续更新。通知到期或手动收起，从最新状态求值，不保存并恢复旧界面。连续通知显示最新一条，不承诺历史队列或条数合并。

设置在独立的 LocalAppData/LingdongCapsule 中原子保存；与 NotchPeninsula 注册表和安装目录隔离。关闭通知功能不改 Windows 策略，通知正文只留内存、不写日志、不上传。升级通过替换程序目录，用户配置单独保存。

发布：MIT 源码、Windows x64 自包含 ZIP、SHA256、构建 CI。ZIP 内提供可选当前用户安装入口，首次引导展示开机启动选项且默认关闭，不要求管理员运行。卸载只移除本程序清单内文件，个人配置保留。0.1 标记预览版，未完成的兼容场景如实写在验证记录中。签名安装包和自动更新延后。

验收：状态自动测试；真实窗口；媒体播放→通知→切歌/暂停→正确恢复；干净目录重建；检查公开文件不含私有配置和证据。支持范围必须按 docs/VALIDATION.md 的实测记录解释。
