# 公开测试版说明

## 下载与启动

从本仓库 Releases 中选择标有 Pre-release 的主程序版本，下载 LingdongCapsule-win-x64.zip 与 SHA256SUMS.txt。插件 API 预览版本不是主程序。

完整解压 ZIP 后，可直接运行 LingdongCapsule.exe，或双击安装.cmd 使用当前用户安装入口。首次启动提供引导，之后主要在托盘常驻，双击托盘图标打开设置。无需管理员权限或另装 .NET SDK。安装、升级、回退和卸载细节见 INSTALLATION.md。

应用内检查更新目前只检查正式版本；测试版更新请查看本仓库 Releases。首个测试版尚无正式版本可供检查，不代表下载包损坏。

程序和安装脚本未签名。使用 Get-FileHash -Algorithm SHA256 核对 ZIP 与同版本校验和；哈希是完整性核对，不是发布者数字签名。只从自己的可信下载来源取得软件，不建议关闭系统安全保护。

## 验证范围和限制

- 主要验收环境为作者本机 Windows 11 x64、单屏 200% DPI。其他显示器、混合 DPI、不同驱动与其他 Windows 版本没有同等实测保证。
- 媒体接入已在本机 QQ 音乐使用，并有独立媒体发布器的工程回归；其他播放器、特殊曲库、歌词来源变化可能存在兼容问题。
- 系统通知需要用户授权，覆盖 Windows 通知中心可提供的来源；不替代系统横幅，不读取聊天数据库。仅声音提示的消息不保证能够显示。
- MSP、Just Solo 与外部时间轴有协议及专用对端测试，不能视为全部第三方真实发送端均已兼容；默认关闭的功能仍由用户主动开启。
- 当前固定版本尚无完整24小时混合运行与长期资源验收，不保证绝对无缺陷。已知明确功能缺陷应修复后发布，未覆盖场景不记作通过。
- 没有多设备同步、云备份或可浏览的历史版本库。设置保存在本机；卸载默认保留个人设置。专注计时停用或退出后不恢复本次倒计时。

本地信息和专注组件、主题、通知权限及歌词操作见 COLLECTION.md、MEDIA.md、NOTIFICATIONS.md。依赖来源和许可见根目录 THIRD-PARTY-NOTICES.md；该测试版不对原 NotchPeninsula DLL 提供二进制兼容。
