# 岛体点击

开启“点击展开媒体控制”后，媒体展开入口跟随“*点击封面返回播放器”：封面跳转开启时，单击封面唤回播放器，右键媒体区展开控制；关闭封面跳转时，单击媒体区展开。展开后点击空白正文不收起；右键展开媒体区直达媒体设置。关闭展开功能改用折叠态按钮，右键媒体区仍可进入媒体设置，重新开启不会恢复之前的隐藏展开状态。

暂停收回时钟后，只要媒体会话仍在且允许展开，点击时钟仍可打开控制。右键时钟或硬件区域直达显示设置。已经打开的设置窗口会恢复并切到对应页，不创建重复窗口；从托盘或再次启动唤回设置会保留原页面。

空闲信息面板打开后，右键收起面板。通知优先采用通知自己的阅读、上滑和来源唤回规则。插件视图已经处理的鼠标事件继续由插件消费。

工程专项通过实际 WPF 窗口的带来源路由事件核对上述入口与邻近状态，也验证组合组件顺序和 Solo 展开恢复。此方法不移动物理鼠标，不证明跨进程物理穿透、真实播放器唤回或混合 DPI 命中均已通过。
