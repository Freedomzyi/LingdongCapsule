# 安装与维护体验改造

Owner 2026-11-06 明确授权并要求建立目标：完整改造安装、使用、卸载和分发，全部完成后目标才结束。

## 交付内容

- 统一 WPF 视觉：沿用应用资源、字体、主题、圆角、按钮、错误弹窗与淡入过渡，不另建不同风格的安装器界面。
- 安装流程：欢迎、安装位置及容量/权限说明、阶段进度、成功与打开应用、失败重试。使用现有文件事务、登记回退与独立用户数据目录。
- 卸载流程：Windows 已安装应用入口进入图形界面，明确删除范围和设置保留；显示阶段进度、完成或失败反馈。维护界面须从独立位置运行，避免自身文件锁阻止卸载。
- 分发：可直接双击的安装程序；ZIP 便携入口继续提供。后台部署脚本隐藏执行，用户只看到完整图形流程。
- 使用流程：复查首次引导、设置、常用弹窗与维护页的字体/按钮/布局/主题/过渡一致性。

## 必须验收

实际深浅主题及短窗口渲染；取消、失败重试、进度/结果状态与重复点击边界；路径合法性、拒绝越界/链接、自有登记和运行中升级回退；卸载自身锁处理、原个人设置和非所属文件保留；真实自包含安装包、下载、CI/版本/源码/校验和一致。只用专用安装目录和测试登记回归，不终止其他日用应用，不安装虚拟机。

## 执行顺序

1. 统一维护界面和可验证的状态/阶段进度。
2. 完成卸载引导与独立运行、清理及登记入口。
3. 完成单文件安装分发入口与打包。
4. 联合验证使用/安装/升级/卸载全部流程，发布新的公开测试版并核对公开下载。
