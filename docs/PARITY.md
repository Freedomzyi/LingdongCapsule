## 开发边界

- 默认独立重写实现，保留自己的架构、窗口和构建链。源码用于理解数据流、公开协议、边界和实际行为，不采用替换名称的整包复制方式。
- 使用第三方依赖时逐项记录来源、版本、许可与分发声明。不得复制未核实授权的图标、音频、字体和品牌素材。
- 功能对齐不要求继承缺陷：不关闭 HTTPS 证书校验，不增加未授权的数据访问，不使用假读数，不修改原版设置、原始通知和私有数据。
- 每项按“未实现 → 已实现 → 自动验证 → 真实场景验证 → Owner 体验反馈”记录，不能用空按钮、静态样例或界面相似替代功能。
- 当前 GitHub 仓库保留开发历史；全项对齐和必要验证完成前不发布成品，不将基础原型称作完成版。
