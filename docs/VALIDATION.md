# 验证记录

## MSP 节点与实际岛体专项

`dotnet run --project tests/Capsule.WindowsTests -c Release -- --msp-test` 使用独立测试发现目录，验证两个 SDK 节点之间的 ping、通知、媒体状态与控制白名单；进一步启动实际 WPF 岛体，通过独立节点调用 notify，确认通知进入岛体状态，安静时段请求返回拒绝且不留旧通知。测试不使用日用共享发现目录、不发送私人消息，不改真实播放器状态。事件广播、订阅及内容块媒体仍未完成。

## Just Solo 本机协议专项

新增实际 WPF 岛体集成测试：临时回环端口发送歌词、进度和播放消息，窗口显示对应歌词；服务端断开后媒体状态与歌词清空。该流程不依赖其他播放器，也不改变用户播放状态。真实 Just Solo 软件的版本兼容、频谱听感及控制交互仍待验证。

本项目自建回环 WebSocket 测试服务验证握手身份、分片歌词、音量命令、服务端关闭后的旧歌词清理、自动重连及握手期间停用取消；命令 `dotnet run --project tests/Capsule.WindowsTests -c Release -- --solo-test` 通过。该测试不启动真实 Just Solo，不等同于真实软件与岛体端到端验收。来源选择已接入岛体歌词/频谱和滚轮音量，设置页分别显示已连接/等待服务状态。
