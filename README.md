# 灵动胶囊

Windows 11 x64 桌面胶囊，支持媒体控制、歌词、系统通知、主题和插件市场。

**公开测试版 beta.8** · [下载安装包](https://github.com/Freedomzyi/LingdongCapsule/releases/download/v0.1.0-beta.8/LingdongCapsule-Setup-win-x64.exe) · [发布说明和便携 ZIP](https://github.com/Freedomzyi/LingdongCapsule/releases/tag/v0.1.0-beta.8)

双击安装包并完成引导。已有用户请先退出托盘中的旧版，再选择原目录覆盖升级。设置从系统托盘打开。开启「自动隐藏」后，胶囊可在重叠时避让前台浏览器标签栏。

欢迎报告问题，请附软件版本、Windows 版本和复现步骤。[问题反馈](https://github.com/Freedomzyi/LingdongCapsule/issues/new/choose)
